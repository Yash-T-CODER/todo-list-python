# ✅ To-Do List CLI App in Python

A simple and effective command-line **To-Do List** application built with Python. This tool allows users to add and remove tasks interactively — helping stay productive and organized through a clean, terminal-based interface.

---

## 🔧 Features

- ➕ Add tasks to your to-do list
- ❌ Remove completed or unwanted tasks
- 👋 Exit anytime with a graceful message
- 🕒 Includes a short delay to simulate real-time interaction

---

```text

2. Remove a task  
3. Exit
